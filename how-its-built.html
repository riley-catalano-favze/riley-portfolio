Riley Catalano/How It's Built

Built by hand.

This portfolio is my favorite case study. Every page is hand-coded in HTML, CSS, and JavaScript, hosted on GitHub, and engineered so people, Google, and AI answer engines all understand exactly who I am.

The stack

Small stack. Big feel.

Fast pages come from fewer moving parts. Everything here loads from the site itself, so it stays quick, private, and fully mine.

01 · Foundation

Hand-coded HTML

Semantic markup on every page: real headings, landmarks, breadcrumbs, and a skip link. All content lives in static HTML, so it reads perfectly with JavaScript on or off.

<main id="main">
  <section>
    <h2>Small stack.</h2>
02 · Design system

One stylesheet of tokens

Color, type, spacing, and easing live as CSS variables, so every page shares the same visual language.

03 · Interaction

Vanilla JavaScript

No framework. Kinetic type, the story timeline, filters, and the Text Riley chat are plain, readable JavaScript.

04 · Hosting

GitHub Pages

Version-controlled on GitHub and served on my own domain, with every change tracked.

05 · Type

Self-hosted variable fonts

Anybody, DM Sans, and Instrument Serif load straight from this site in compact WOFF2 files.

06 · Scroll

Lenis smooth scroll

Silky scrolling on desktop that runs on native scroll, so anchors, sticky elements, and keyboards keep working.

Play with it

Type that moves.

The headline font, Anybody, is a variable font with a width axis from 50% to 150%. That single file powers the kinetic name on the homepage. Drag the sliders and feel it stretch.

Search + AI visibility

Speaking machine.

I learned SEO and AI optimization by building this site. Structured data tells Google, ChatGPT, Perplexity, and Gemini exactly who Riley Catalano is, which solved a real name-disambiguation challenge through clear entity signals.

Built for everyone

Motion with manners.

Big effects only matter when every visitor enjoys them. The site adapts to each person, device, and preference.

01

Your motion, your choice

The site honors your device’s reduced-motion setting, and the switch in the footer lets you turn animation on or off anytime.

02

Keyboard friendly

Search, filters, the opening book, and the chat all work with a keyboard, with clear focus outlines throughout.

03

Smooth page changes

Cross-document view transitions fade each page into the next in supporting browsers, and every other browser navigates instantly.

04

Phone first

The horizontal story becomes a vertical one, cursor effects step aside for touch, and the chat opens full screen.
